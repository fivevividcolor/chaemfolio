# CHAEM — LOOK BEYOND.

Interactive optical-glass portfolio homepage.

## Deployment

This is a static single-page website. Keep `index.html` in the repository root. In Vercel, use the **Other** framework preset, with no build command and `.` as output directory if prompted.

## Updating

Edit `index.html`, commit to the `main` branch, and Vercel will deploy automatically once the existing project is linked to this GitHub repository.

## Note

Google Fonts (Montserrat) loads from the internet. Project tiles 2 and 3 are placeholders; contact content is not final.
